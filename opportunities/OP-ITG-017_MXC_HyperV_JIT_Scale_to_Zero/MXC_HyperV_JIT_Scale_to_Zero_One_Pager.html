How the MXC Hyper-V Engine Works

  • Preserved Sleep (0.0% Idle vCPU): Pre-trimmed Windows Server 2025 Golden Images stay suspended in host RAM with virtual CPU scheduling dropped strictly to zero between requests.
  • JIT Ingress Gateway (<300ms Resume): Connection-buffering ingress holds incoming HTTPS/API sockets, invokes wxc-exec --features hyperv to unpause a standby guest, verifies health, and forwards payloads with zero dropped connections.
  • Sterile Session Reset (.avhdx Diff Disks): Every workload or AI agent runs on a transient differencing disk; on release or idle timeout, the delta disk is incinerated and reset to pool-clean-baseline.
  • Identity-Bound Leasing (ADR-008) & Autoscaling: Binds each isolated sandbox to a verified MFA user or Entra AI Agent ID while watermark autoscaling replenishes warm pools ahead of bursts.
