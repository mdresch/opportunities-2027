# Hypothesis Register — Opportunities 2027

> **Lifecycle Stage:** `Stage 2 (Hypothesis)` — bridges Tier 1–2 Ideation and Stage 3–4 Pre-Pilot Gates (see [Tailored-Hybrid-SIDPA-Governance.md §3 Stage 2](../governance/Tailored-Hybrid-SIDPA-Governance.md#stage-2--hypothesis-tier-2-falsifiable-assumptions)).  
> **Honest Evidence Baseline:** All hypotheses start as `Formulated` with zero fabricated market-test outcomes. Append dated **Evidence / Updates** only from real buyer conversations, outreach, IP audits, or pilot data; never rewrite the original statement or reuse IDs.

## Writing Standard & 6-Action Status Lifecycle

- **Formula:** *We believe **[Buyer]** will **[Observable Action]** because **[Pain/Trigger]** → True if **[Success Threshold & Sample]** within **[Time Box]**; False if **[Falsification Criteria]**.*
- **Allowed Statuses (SIDPA `classify-hypothesis-status`):** `Formulated` · `Formulated/Blocked` *(named blocker)* · `Testing` *(active test plan)* · `Validated` · `Invalidated` · `Inconclusive` · `Human Review` *(ambiguous evidence escalated to Director)*.
